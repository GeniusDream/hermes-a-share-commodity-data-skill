# A 股与商品数据采集 Skill

给 Hermes 使用的数据采集 skill，用于研究国内原材料商品与 A 股行业 / 概念板块之间的联动关系。

安装后，量化同学可以直接用自然语言让 Hermes 采集数据；不需要手动记命令参数。

## 支持的数据

| 研究对象 | 当前支持 | 边界 |
|---|---|---|
| 国内商品期货 | 74 个国内商品连续合约 | 不含金融期货、海外期货、具体月份合约 |
| 商品行情 | 快照、分钟线、日 K | 来自新浪公开接口，分钟线可用性依赖源站 |
| A 股板块 | 同花顺行业板块、同花顺概念板块 | 不含申万、东方财富、中证等其他板块体系 |
| A 股指数 | 上证指数、深证成指、创业板指 | 不是全指数库 |
| 新闻 / 快讯 | 东方财富财经新闻、华尔街见闻快讯 | 原始新闻采集，不做事件归因 |

## A 股板块边界

当前 A 股板块数据基于同花顺行业 / 概念板块。

建议流程：

1. 先让 Hermes 搜索板块名。
2. 再采集对应板块日线。
3. 用商品日 K / 分钟线与板块日线做后续研究。

注意：板块名称需要与同花顺 / AKShare 返回名称一致。这个 skill 已支持板块名搜索，避免手动猜名称。

## 输出字段

采集结果统一输出为 JSON、JSONL 或 CSV，常见字段包括：

| 字段 | 含义 |
|---|---|
| `source` | 数据源 |
| `dataset` | 数据集类型 |
| `name` | 商品、指数、板块或新闻名称 |
| `code` | 数据源代码 |
| `trade_date` | 交易日 |
| `timestamp` | 时间戳 |
| `open` / `high` / `low` / `close` | 行情价格字段 |
| `pct_chg` | 涨跌幅 |
| `amplitude` | 振幅 |
| `amount` / `volume` | 成交额 / 成交量 |
| `title` / `body` / `url` | 新闻字段 |
| `raw` | 源站原始载荷 |

## 功能边界

这个 skill 只提供数据采集能力。

它不会自动完成：

- 商品与 A 股板块相关性分析；
- 因果判断；
- 投资结论；
- 长期数据库入库；
- 定时任务调度。

这些可以由 Hermes 基于采集结果继续完成，或接入用户自己的量化研究 pipeline。

## 安装

```bash
git clone https://github.com/GeniusDream/hermes-a-share-market-data-pack.git
cd hermes-a-share-market-data-pack
./install.sh --test
```

指定 Hermes profile：

```bash
HERMES_HOME=~/.hermes/profiles/your-profile ./install.sh --test
```

安装后会写入：

```text
$HERMES_HOME/scripts/a_share_data_collector.py
$HERMES_HOME/venvs/a_share_data/bin/python
$HERMES_HOME/skills/data-science/a-share-data-collection/SKILL.md
```
